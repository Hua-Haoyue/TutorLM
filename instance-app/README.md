# Instance Application

本目录属于容器内团队。前端已提供租约页面生命周期与邀请码入口模块，业务后端与完整工作台尚未实现。

预留归属：

- `backend/`：应用 Runtime Host、业务分层、插件和任务管理。
- `frontend/`：学习工作台，以及浏览器端租约和应用会话接入逻辑。
- `deploy/`：应用 Dockerfile、镜像构建与交付脚本，不放网关或控制面。

`frontend/` 提供两个可直接挂载的同源模块：邀请码入口表单（申请计算租约）与
关闭工作台释放计算的生命周期模块，详见 `frontend/README.md`。完整工作台仍未提供，
页面不会自动获得这些能力，需显式挂载或安装。

内层团队可以独立提供镜像和静态前端制品供外层联调；不需要依赖外层源码，
也不需要共享数据库或安装控制面的 Python 包。

持久项目接入前先阅读 `../contracts/instance-runtime-v2.md`，匿名临时模式见 v1。
外层已提供项目 UUID 和独立持久卷；应用仍需实现稳定项目存储、重新建立会话后的内容恢复，
以及不会清理持久项目的 session GC。未满足就绪确认协议的镜像不能用于持久项目。
`/internal/status`、可信 drain 与自动租约到应用会话交换尚未实现，不应作为现有能力依赖。
