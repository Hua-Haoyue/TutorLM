# Cross-Boundary Contracts

- `instance-runtime-v1.md`：匿名临时租约的运行契约。
- `instance-runtime-v2.md`：持久项目与临时计算分离的运行契约。
- `instance-runtime-v3.md`：项目数据子目录、卷外会话目录与卷复制（分享/克隆）的运行契约。
- `gateway-lease-v1.md`：浏览器、网关与控制面的基础租约契约。
- `gateway-lease-v2.md`：邀请码准入与项目分享导入的租约契约。

这里记录协议，不放共享 ORM、数据库 schema、应用服务或 Python 工具包。
协议描述当前项目的接口约定和开发边界。
未实现的协议明确标记为后续工作；破坏性变化须另建版本并由两侧共同评审。
