# 控制面评审清单

以 `../../contracts/` 和 `../../docs/architecture.md` 为接口与职责边界。
以下为变更评审项，不是执行结果记录。

## 分配与鉴权

- [ ] 并发分配不超卖槽位，不为不同租约分配同一代次的实例。
- [ ] 有效 Cookie 重复申请复用租约，独立访客使用独立客户端测试。
- [ ] Cookie 与应用 Bearer 同时存在时，正确区分两层身份。
- [ ] 过期或撤销的租约立即失去准入资格，不依赖后台 GC 才生效。
- [ ] 客户端提供的槽位、代次和 upstream 不影响路由目标。
- [ ] 管理接口需要管理令牌，并被公网网关拒绝访问。
- [ ] 公开响应不泄漏内部 upstream、token_hash、邀请码明文或配置密钥。

## 邀请码与准入

- [ ] 系统码与分享码前缀、密码空间与哈希域隔离，分享码不能提升为系统优先级。
- [ ] 邀请码明文只在签发响应出现一次；列表、撤销、日志与事件都不含明文。
- [ ] `invitation_only=true` 时无码/错码申请被拒，且旧 Cookie 的幂等复用也不能绕过。
- [ ] 仅由服务端判定码类型与优先级，客户端提交的类型/优先级字段被忽略。
- [ ] 撤销系统码写入持久 tombstone，配置重新预置同一码重启也不复活。
- [ ] 系统码抢占只回收计算、保留被抢占项目的持久卷，且不声称任务无损。

## 生命周期与数据

- [ ] 只有就绪探针返回 HTTP 200 且 `status=ok` 才允许访客接入；持久模式确认 `workspace_id` 与存储布局。
- [ ] 每个计算租约使用独立容器，只挂载对应 workspace 的卷与数据子目录，不发布宿主机端口。
- [ ] 计算回收撤销准入、删除旧容器并推进 generation，保留持久项目卷。
- [ ] 项目连续闲置超过 4 小时且无运行或隔离引用时，原子认领后删除其卷。
- [ ] 用户 UUID 必须配合恢复凭据，不能直接授权读取项目。
- [ ] 清理失败进入隔离，不把残留数据重新分配。
- [ ] 控制面重启后对账，不将未完成清理的槽位视为空闲。
- [ ] 只操作归属标签匹配的资源，不影响其他项目或开发者。
- [ ] 不把会话级任务列表或缺少 HTTP 请求当作实例空闲的证明。

## 项目分享与卷复制

- [ ] 只有声明 v3 `content_only` 布局的项目才能签发分享码与作为复制源。
- [ ] 复制前源项目计算已停止/回收并确认退出，不复制运行中的数据库文件。
- [ ] 副本是接收用户的新 UUID、新卷；接收者不能挂载或读写源项目数据。
- [ ] 复制显式排除会话/凭证子树，避免把源应用会话变成接收者身份。
- [ ] 目标项目在复制期间不可分配、不可被存储 GC 回收；失败不发布半成品，源保持原状。
- [ ] helper 镜像必须是本机已有镜像，绝不隐式拉取；helper 停止与删除失败要暴露而不是吞掉。
- [ ] 导入成功后为副本记录普通 trial 授权，`invitation_only=true` 时接收用户仍能打开自己的副本。

## 部署与协作

- [ ] 应用和控制面不共享数据库、不相互导入私有模块。
- [ ] Docker socket 只提供给控制面，不提供给业务实例或网关。
- [ ] 不同开发环境使用独立网络、端口、卷、标签和凭据。
- [ ] 模型、SSH、管理与访客凭据不写入版本控制；真实控制面配置文件不入库。
- [ ] 配置文件与环境变量分层正确：环境覆盖文件，`--config`/`CONTROL_PLANE_CONFIG` 决定文件路径。
- [ ] 公网使用前完成 TLS、Secure Cookie 和权限配置评审。
- [ ] 真实 Docker 测试显式启用，使用独立前缀并清理自身资源。
- [ ] 跨层接口变化更新版本化契约，并由两侧共同评审。
- [ ] 控制面测试、前端测试与静态跨边界 import 检查通过。
