工作方式 · How it works

读到哪里，
问到哪里。

从导入一份资料，到把零散的问答整理成一份讲稿。下面是 TutorLM 的完整使用流程，以及工作区里每个区域的作用。

四步流程工作区的三个区域节点、追问与优化解释键盘快捷键导出与分享

四步流程

  1. 导入资料。在左侧资源栏导入 .md / .txt，或新建文档直接粘贴正文。文档导入后不会自动生成节点，由你圈选正文决定哪些内容成为知识节点。
  2. 选中即提问。在阅读区划选一段文字（或在选区上点右键），输入疑问或直接点「解释」。新节点一直与原文相连，原文中的这段文字按你选择的颜色高亮。
  3. 越问越深。在解释里再圈一个词，可以「追问」生成下一层节点，也可以加粗、斜体、高亮做标记。直接在节点的对话框里提问，则以对话的形式留在节点里。
  4. 优化与串讲。当一个节点下面已经有追问节点时，「优化解释」会汇总你圈画过的词和更深层的解释，重新生成一版；旧版本保留，可以翻页对比。最后按依赖顺序一键串讲，导出为 Markdown。

工作区的三个区域

区域作用
资源栏（左）文档列表、筛选（Ctrl P）、导入与删除。数字表示该文档的节点数。
阅读区（中）MD / RAW / 版式三种视图，大纲、查找、高亮、专注模式。原文中被提问过的词按你选择的颜色高亮。
知识图（右）节点卡片与连线。默认跟随阅读区滚动；右侧的缩略条标出哪些位置有节点连回原文、解释有多深，点击即可跳转。

三个区域之间的分隔条都可以用鼠标拖动调整宽度，宽度会被记住。标题栏里「TutorLM」右侧的齿轮是偏好设置：主题（浅色 / 深色 / 跟随系统）、解释的长短与风格、高亮颜色、是否跟随滚动等。

节点、追问与优化解释

节点里有什么

  • 解释页：每次「解释」或「优化解释」生成一页，用翻页按钮切换展示哪一版。
  • 对话：在节点底部的输入框里直接提问，问答以对话气泡显示，可以用滚轮翻看。
  • 笔记：节点的标题与内容可以直接编辑，停止输入后自动保存。

在解释里圈词

选中解释中的文字会出现一个小工具条：追问（生成下一层节点）、加粗、斜体、高亮和查找（在原文中查找这个词）。这些标记都保存在服务器上。

优化解释

只有当节点下已经有追问节点时才可用。它会递归收集这一页里你圈画过的词、以及每个追问节点的最新解释，把它们作为提示重新请求一次解释；原来的解释不会被覆盖。

解释的长短与风格来自偏好设置，会作为提示附加在提问后面发送给模型。

导出与分享

阅读区右上角的「导出」可以下载当前文档与节点解释（Markdown）或整张知识图（JSON）。导出内容都是服务器上的当前数据。分享会生成一个分享码，对方兑换后得到一份独立的副本，双方的修改互不影响。
